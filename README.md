# WhatsApp Clone using HTML, CSS, and JavaScript

This project is a simplified clone of the WhatsApp web interface, built using HTML, CSS, and JavaScript. It aims to replicate the core front-end functionality and design of WhatsApp Web, providing a familiar messaging experience.  This is a front-end focused clone, and does not include backend functionality for real-time messaging.

## Features

*   **User Interface:**  Replicates the basic layout and styling of WhatsApp Web, including the chat list, message area, and input field.
*   **Chat List:** Displays a list of simulated contacts/groups.  Clicking on a contact/group opens the corresponding chat. (Static/mock data)
*   **Message Area:** Displays simulated chat messages. Messages are displayed with different styles for sent and received messages. (Static/mock data)
*   **Message Input:** Allows users to type and "send" messages (simulated).  The sent messages are displayed in the chat area.
*   **Responsive Design:** Adapts to different screen sizes for optimal viewing on desktops, tablets, and mobile devices.
*   **Modern UI/UX:** Emulates the WhatsApp Web look and feel for a familiar user experience.

## Technologies Used

*   **HTML:** Structures the content and layout of the web pages.
*   **CSS:** Styles the visual presentation of the website, including layout, colors, fonts, and responsiveness.
*   **JavaScript:** Adds interactivity and dynamic behavior, such as handling user input, updating the chat display (with mock data), and basic UI interactions.
